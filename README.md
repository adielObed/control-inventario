1. Descripción del Proyecto 🚀

Sistema de Gestión de Usuarios e Inventario
Esta es una API REST desarrollada con Node.js, Express y MongoDB diseñada para el control de personal y materiales en contenedores de trabajo. El sistema permite gestionar el ciclo de vida completo de los usuarios (CRUD) y asegura el acceso mediante autenticación basada en JSON Web Tokens (JWT).

Características principales:

🔐 Autenticación segura: Registro e inicio de sesión con contraseñas encriptadas mediante bcryptjs.

🛡️ Rutas protegidas: Middleware de autorización para validar tokens JWT.

👥 Gestión de usuarios: Operaciones completas para listar, ver, actualizar y eliminar usuarios.
